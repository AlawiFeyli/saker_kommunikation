# saker_kommunikation
Dag 7 fokuserar på att säkra en kommunikationsväg i IoT‑caset genom kryptering, certifikatverifiering och åtkomstkontroll. Arbetet demonstrerar hur en klient verifierar en broker eller tjänst, hur felaktiga identiteter stoppas och hur behörighet skiljs från transportskydd. Två separata demos används: MQTTS och HTTPS.
